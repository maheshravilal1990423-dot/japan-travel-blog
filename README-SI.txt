iPhone එකෙන් publish කිරීම:
1. GitHub account එකක් නැත්නම් github.com වෙත ගොස් account එකක් සාදන්න.
2. New repository එකක් හදන්න. උදා: japan-travel-blog. Public තෝරනවා නම් repository එකේ files ඕනෑම කෙනෙකුට බලන්න පුළුවන්.
3. Safari browser එකෙන් repository එකට ගොස් Add file > Upload files තෝරන්න. ZIP එක extract කරලා ඇතුළේ files/folders upload කරන්න (ZIP එක විතරක් upload කරන්න එපා).
4. Settings > Pages > Build and deployment > Deploy from a branch තෝරන්න; branch main සහ folder /(root) තෝරා Save කරන්න.
5. GitHub Pages URL එක Settings > Pages хэсэгт පෙන්гэнэ. Publish වීමට ටික වෙලාවක් ගත විය හැකියි.
